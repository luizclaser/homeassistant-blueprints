# 🏡 Minhas Blueprints para Home Assistant

### 💡 Iluminação Noturna - Múltiplos Sensores e Lâmpadas
Automação para acender luzes/interruptores por sensores de movimento ou abertura de porta durante a madrugada, desligando automaticamente após o tempo configurado.

[![Importar Blueprint](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https://raw.githubusercontent.com/luizclaser/homeassistant-blueprints/refs/heads/main/iluminacao_noturna.yaml)

### 💡 Desligar Lâmpadas por Ausência de Presença Humana
Automação para desligar luzes/interruptores em horario especificado se não for detectado pessoas por um tempo determinado.

[![Importar Blueprint](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fraw.githubusercontent.com%2Fluizclaser%2Fhomeassistant-blueprints%2Fmain%2Fdesligar_por_ausencia.yaml)
